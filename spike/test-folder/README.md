# Field Vault

A small **local-first** vault used to exercise the Kanwas canvas. Every folder
becomes a canvas; every `.md` file becomes a rich-text node.

## Contents

- [Expedition Notes](expedition-notes.md) — the main field report
- `writing/` — reusable writing skills (nested canvas)
- `reference/` — quick index
- `media/` — images

## Why this exists

> The folder is the source of truth. Delete Kanwas and your data is still just
> a folder of markdown.

### Quick checklist

1. Point Kanwas at this folder
2. Watch it render as a spatial canvas
3. Edit a file on disk and see the node reload

Inline styles: _italic_, **bold**, `code`, and a [link](https://kanwas.ai).
